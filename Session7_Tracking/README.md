# Tracking

## Introduction
When you collect time series, you are most likely interested in the movement of objects in space and time.  The objects could be cells on a dish, cells or nuclei in a developing animal or plant, subcellular compartments such as mitochondria or vesicles within living cells, (single) molecules moving on a slide, etc.  Tracking these objects over time will give you information about their speed, direction, type of motion (is it a random walk, or is there directionality), and can also be used for lineage tracing of cells/nuclei within organisms.

Tracking usually starts with segmentation of objects (using the approaches you have practiced in the previous sections), followed by linking the objects in consecutive frames into tracks, where each track follows a single object.  The higher the density of objects in the image, the harder it is to determine which object is which in the next frame.  You will want to use all information about the objects that is available (such as location, size, shape, intensity, etc.) to most reliably link objects from one frame to the next.  Thus, tracking is harder with objects that reveal little (such as single molecules, which all look the same) and you should collect as much distinguishing data about your objects as possible.  The density of objects and the ease with which they can be identified determine how far they can travel between frames and still be identified reliably.  You will want to have some idea about this before you acquire the data, so that you can choose the optimal frame rate.

A common problem is an object disappearing from your segmented images for one or more frames.  You can either end a track when this happens, continue looking in later frames, or possibly even go back to the raw images to see if the object was missed during segmentation.  Obviously, all this will complicate your code, and you will only want to go that route when absolutely needed.

The following example is based on [the excellent tutorial by Robert Haase](https://haesleinhuepf.github.io/BioImageAnalysisNotebooks/34_timelapse_analysis/tracking.html?highlight=time+lapse), which uses data from [Tinevez, J. & Guillaume Jacquemet, G.](https://zenodo.org/record/5206107#.ZFthHnZBxPa) licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode).  The tutorial uses the library [btrack](https://btrack.readthedocs.io/en/latest/index.html), which is described in [this publication](https://doi.org/10.3389/fcomp.2021.734559).  If you use btrack in work that you publish, you should cite this publication.  Btrack uses a Bayesian cell tracking approach that employs estimates of location based on past movement calculated using [Kalman filters](https://en.wikipedia.org/wiki/Kalman_filter). Btrack also handles cell divisions and missing frames.
